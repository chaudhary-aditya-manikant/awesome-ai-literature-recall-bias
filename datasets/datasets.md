# Datasets

## OpenAlex
https://openalex.org/

OpenAlex provides scholarly publication and citation data. It can be used to analyse highly cited and less-cited papers and their citation relationships.

## Semantic Scholar Open Research Corpus (S2ORC)
https://github.com/allenai/s2orc

A large collection of scientific papers and related metadata. It can be used for research involving scientific text, citations, and literature analysis.

## SYNERGY Dataset
https://github.com/asreview/synergy-dataset

A dataset for studying systematic-review screening. It is useful for experiments involving automated literature screening and active learning.
