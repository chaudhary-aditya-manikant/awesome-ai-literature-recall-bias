# GitHub Repositories

## 1. ASReview

https://github.com/asreview/asreview

ASReview is an open-source tool for screening research records using active learning. It is closely related to the paper's discussion of automated literature screening and the risk of changing which papers are examined first.

## 2. S2ORC

https://github.com/allenai/s2orc

The Semantic Scholar Open Research Corpus provides tools and data for working with scientific papers and their citation information. It is relevant to analysing large collections of research papers and citation relationships.

## 3. OpenAlex API Tutorials

https://github.com/ourresearch/openalex-api-tutorials

This repository contains examples for working with OpenAlex data. The examples are useful for retrieving publication and citation information and can support analysis of citation patterns.

## 4. Connected Papers Python Client

https://github.com/ConnectedPapers/connectedpapers-py

A Python client for the Connected Papers service. It can be used to explore related research papers and citation-based connections between publications.

## 5. Semantic Scholar API

https://github.com/allenai/s2-api

The Semantic Scholar API provides programmatic access to scholarly papers, authors, citations, and references. It is relevant to automated paper discovery and citation-based literature analysis.
