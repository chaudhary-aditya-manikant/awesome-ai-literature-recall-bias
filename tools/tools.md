# Tools

## 1. ASReview

https://asreview.ai/

ASReview is software for screening large collections of research records with active-learning methods. It is particularly relevant to automated literature screening.

## 2. OpenAlex

https://openalex.org/

OpenAlex provides an API for retrieving scholarly metadata and citation relationships. It can be used to collect publication and citation information for analysis.

## 3. Semantic Scholar

https://www.semanticscholar.org/

Semantic Scholar is a research discovery platform for searching papers and exploring related work. It can help with finding papers and examining connections between publications.

## 4. Google Scholar

https://scholar.google.com/

Google Scholar is a general academic search engine. It provides a useful comparison point when looking at how different scholarly search systems discover papers.

## 5. VOSviewer

https://www.vosviewer.com/

VOSviewer is software for creating and visualising bibliographic networks, including citation, co-authorship, and keyword relationships.
